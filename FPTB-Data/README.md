# ML-FPTB-Non-Adiabadic-Dynamics
Machine Learning First Principles Tight Binting Non-Adiabadic Dynamics


Folder/files contain the following:


  structure-pol-field.xsf  : nano-domain structure with polarization in units of C/m^2.

  diffusion_data           : contains diffusion data for x, y, and z directions with time step of 0.5 fs

  phonon_power_spectrum    : contains Br projected phonon power spectrum in units of 1/meV and meV for colums 1 and 2 respectivly. File names inidcate temperature in Kelvin.

  electron-hole-energy.dat : hole and electron energies for plot for figure 3. First column is holes second column is electrons. Timestep is 0.1 fs.

  charge_distribution      : contains carrier distributions for projectes used for figure 4 in numpy format.
