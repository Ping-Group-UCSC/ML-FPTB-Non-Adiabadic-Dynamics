This example illustrates the fitting procedure, NOTE this is an example and does not use all the MD frames used in the paper.

model functions are defined in models.py  
"features", which are inputs for the models, are defined in featurefns.py   
data for fitting is in wanndata/
run fit.py to fit the models to the data
the output is *_params.dat for the best-fit parameters, and *_fit.dat for the comparison between data and predictions.
