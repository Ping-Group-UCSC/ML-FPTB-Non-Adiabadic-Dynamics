gen_features.py is a script that takes atomic coordinates and  writes features files 

INPUTS:

coord.xyz : atom coordinate file

atom_index.dat records the order of atoms in the .xyz file in the following format

    atom_index atom_label ix iy iz

    where ix iy iz are the integer unit cell coordinates.

orb_index.dat records the order of orbitals in wannier90

(helper scripts atom_index.py and orb_index.py are available to generate these files for general supercells)

shells/ folder contains information about m-th neighbor shells, generated by shells/shells.py 

OPTIONS:

mshells_* are the main variables controlling how many shells to include in the feature set. 

OUTPUT:

*_ts_n.dat contain feature lists in this format:
dx dy dz orb1 orb2 features...


HOW TO EXTEND THE CODE:

1) The user has to construct a list of hoppings, which is a list of [dx,dy,dz,orb1,orb2]. 
Some of these have already been defined in gen_features.py. 
See comments in the script for how to extend it to other hoppings.

2) The user has to define a function that calculates features, given the timestep and the orbital index orb1, orb2.
Wissam's geometry features are already included here.
See comments for how to write new feature functions.


In this script, information on orbital/atom properties are accessed by calling lut.get(...)
Examples:

find the atom index of an orbital
lut.get("orb",orb,"atom")

find the orientation of a p-orbital
lut.get("orb",orb,"pdir")

find the spin of an orbital
lut.get("orb",orb,"spin")

find all orbitals that are spin up
lut.get("spin","up","orb")

find all Pb:s orbitals that are spin up
lut.get("spin","up", "orb_typ","Pb:s", "orb")

find the Pb:s orbitals in unit cell ix,iy,iz
lut.get("ix",ix, "iy",iy, "iz",iz, "orb_typ","Pb:s", "orb")
(will return both spin up and spin dn orbitals)
